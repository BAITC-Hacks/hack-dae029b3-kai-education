# Есть дефект или нет

Учебный скрипт принимает путь к одной картинке и печатает `OK` или `DEFECT`.
В комплекте два квадрата 128 × 128 пикселей: зелёный `ok.png` и красный
`defect.png`. Модель и API-ключи не нужны.

## Как запустить

Нужен Python 3.10 или новее. Из корня репозитория в PowerShell:

```powershell
py -3 -m pip install -r defect-detector/requirements.txt
py -3 defect-detector/detect.py defect-detector/ok.png
py -3 defect-detector/detect.py defect-detector/defect.png
```

Результаты соответственно: `OK` и `DEFECT`.
На macOS/Linux замените `py -3` на `python3`.
Для своей картинки передайте её путь вместо пути примера; путь с пробелами
заключите в кавычки. Поддерживаются PNG, JPEG и другие форматы Pillow.

## Правило и результат

Пиксель считается красным, если R ≥ 150, R ≥ 1,5 × G и R ≥ 1,5 × B.
Если таких пикселей не менее 20% от общего количества, результат — `DEFECT`,
иначе — `OK`. Прозрачные изображения проверяются на белом фоне.
Зелёный пример содержит 0% красного, красный — 100%.

Успешная проверка печатает только метку и завершается с кодом 0, в том числе
для `DEFECT`. Ошибка чтения выводится в stderr с кодом 1; неверные аргументы —
с кодом 2. Это демонстрация правила по цвету: красный предмет тоже будет
признан браком, а дефект без красного цвета может быть пропущен.
