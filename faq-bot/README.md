# FAQ-бот на 5 вопросов

## Сайт с чатом

В корне репозитория дважды нажмите `start-faq-site.cmd`: откроются сервер
и сайт в браузере. Окно сервера нужно оставить открытым.
Или запустите из PowerShell:

```powershell
cd "C:\Users\Hp\Documents\Codex\2026-07-30\kai-agent-archive-2026-08-03\hack-dae029b3-kai-education"
py -3 -B faq-bot/server.py
```

Откройте http://127.0.0.1:8000. Если порт занят, используйте `--port 8001`
и адрес http://127.0.0.1:8001. На macOS/Linux замените `py -3` на `python3`.
Остановка — Ctrl+C. Python 3.10+, без установки пакетов.

Сайт адаптируется к телефону, содержит пять быстрых вопросов, ввод с Enter,
историю диалога и кнопку «Новый диалог». История хранится только в этом браузере
(до 100 сообщений); новый диалог очищает её. Если браузер запрещает хранение,
чат продолжает работать без сохранения. При ошибке связи появляется пояснение.
Сайт и терминальный бот используют один `faq.txt` и одинаковые правила ответа.
Сервер предназначен для локальной демонстрации, доступен только на компьютере,
где запущен. Исходники сайта на GitHub сами по себе не создают публичный сайт.

## Чат в терминале

Чат в терминале отвечает на вопросы про время репетиции, команду, трек,
сдачу и призы. Пять пар вопрос–ответ хранятся в `faq.txt` в UTF-8:
одна пара на строку, между вопросом и ответом — табуляция.

## Как запустить

Нужен Python 3.10 или новее, установка пакетов не требуется.
Из корня репозитория в PowerShell:

```powershell
py -3 faq-bot/bot.py
```

На macOS/Linux используйте `python3 faq-bot/bot.py`.
Введите вопрос и нажмите Enter. Для завершения — `/exit`, `выход` или Ctrl+C.
Файл FAQ ищется рядом со скриптом независимо от текущей папки.

## Что получилось

| Пример вопроса | Результат |
|---|---|
| Когда начинается репетиция? | Уточнение времени у организаторов, длительность кейса 30–60 минут |
| Какая у нас команда? | Репозиторий команды и пояснение о составе |
| Какой у нас трек? | Пояснение о треке и список учебных кейсов |
| Куда загрузить работу? | Ссылка на репозиторий и требования к README |
| Какие будут награды? | Уточнение информации о призах у организаторов |
| Какая погода? | не знаю |

Бот выбирает тему с наибольшим числом совпавших ключевых слов; учитывает
регистр, заменяет «ё» на «е» и использует начала слов для разных окончаний.
Если совпадений нет или несколько тем набрали одинаковый максимальный балл,
отвечает «не знаю». Это простые правила, без модели и RAG: возможны ложные
совпадения, например вопрос о времени другого события.

Точное время, состав команды, официальное название трека и призы не были
даны в задании, поэтому ответы честно отмечают отсутствие этих сведений.
После уточнения измените ответы в `faq.txt`, сохранив порядок пяти тем.
