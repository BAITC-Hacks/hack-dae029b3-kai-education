# faq5questions

FAQ-помощник команды Kai Education для репетиции хакатона. Отвечает на пять
заранее известных тем: время, команда, трек, сдача и призы. Проект работает
как адаптивный сайт с чатом и как программа в терминале.

Вопрос сопоставляется с темами по ключевым словам. Если совпадений нет или
результат неоднозначен, бот отвечает «не знаю». Ответы хранятся в `faq-bot/faq.txt`;
веб-версия и терминальная версия используют одну базу и одну логику.
LLM, RAG, внешние API и ключи доступа не требуются.

## Возможности

- Тёмный интерфейс с адаптацией для телефона и компьютера.
- Пять кнопок быстрых вопросов и свободный ввод с отправкой по Enter.
- Сохранение последних 100 сообщений в браузере и очистка диалога.
- Понятное сообщение при ошибке связи с сервером.
- Запуск локального сайта двойным щелчком на Windows.

## Запуск FAQ

**Сайт Kai Education:** запустите `start-faq-site.cmd` двойным щелчком
или выполните `py -3 -B faq-bot/server.py` и откройте http://127.0.0.1:8000.
Нужен Python 3.10+, зависимости не требуются. [Подробнее](faq-bot/README.md).

Для терминальной версии выполните `py -3 faq-bot/bot.py` из корня репозитория.
На macOS/Linux замените `py -3` на `python3`.

## Результат и ограничения

Проверены пять тем, перефразировки, неизвестный вопрос, сохранение и сброс
истории, ошибка сети и интерфейс на размерах 1586 × 992 и 390 × 844.
Это учебный бот: он не ищет актуальную информацию в интернете и может ошибаться
на сложных формулировках. Неизвестные сведения о репетиции не выдумываются.
Сервер работает локально; публичный хостинг не настроен.

## Классификатор обращений

Небольшой скрипт на JavaScript разбирает пять готовых обращений из `messages.txt`.
Для каждого печатает исходный текст, категорию и один черновик ответа на русском.
Используются правила по ключевым словам: LLM, API-ключи, интернет и сторонние пакеты не нужны.

## Как запустить

Нужен Node.js 18 или новее. В папке репозитория выполните:

```sh
node classifier.js
```

Файл `messages.txt` хранится в UTF-8: одно обращение на строку. Пустые строки
игнорируются. Скрипт ищет файл рядом с собой, поэтому работает и при запуске
из другой папки по пути к `classifier.js`.

## Что получилось

| № | Обращение | Категория |
|---|---|---|
| 1 | Как получить справку о месте учёбы? | справка |
| 2 | В столовой очередь, еда холодная. | жалоба |
| 3 | Хочу записаться на консультацию завтра. | другое |
| 4 | Пропал Wi‑Fi в корпусе B. | жалоба |
| 5 | Где парковка для гостей? | другое |

«Справка» здесь означает запрос документа, а не любой информационный вопрос.
Сообщение о неисправности Wi-Fi считается жалобой. Правила проверяются сверху
вниз до первого совпадения; неизвестный текст получает категорию «другое»
и просьбу уточнить детали. Правила и шаблоны ответов находятся в `classifier.js`.

Ответы являются черновиками: они не отправляются, не подтверждают запись
и не выдумывают адрес парковки или сроки оформления документов.
Это учебный пример для пяти заданных текстов: перефразировки, отрицания
и обращения с несколькими темами могут потребовать доработки правил.
