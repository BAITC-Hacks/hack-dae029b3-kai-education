# Классификатор обращений

Небольшой скрипт на JavaScript разбирает пять готовых обращений из `messages.txt`.
Для каждого печатает исходный текст, категорию и один черновик ответа на русском.
Используются правила по ключевым словам: LLM, API-ключи, интернет и сторонние пакеты не нужны.

## Как запустить

Нужен Node.js 18 или новее. В папке репозитория выполните:

```sh
node classifier.js
```

Файл `messages.txt` хранится в UTF-8: одно обращение на строку. Пустые строки
игнорируются. Скрипт ищет файл рядом с собой, поэтому работает и при запуске
из другой папки по пути к `classifier.js`.

## Что получилось

| № | Обращение | Категория |
|---|---|---|
| 1 | Как получить справку о месте учёбы? | справка |
| 2 | В столовой очередь, еда холодная. | жалоба |
| 3 | Хочу записаться на консультацию завтра. | другое |
| 4 | Пропал Wi‑Fi в корпусе B. | жалоба |
| 5 | Где парковка для гостей? | другое |

«Справка» здесь означает запрос документа, а не любой информационный вопрос.
Сообщение о неисправности Wi-Fi считается жалобой. Правила проверяются сверху
вниз до первого совпадения; неизвестный текст получает категорию «другое»
и просьбу уточнить детали. Правила и шаблоны ответов находятся в `classifier.js`.

Ответы являются черновиками: они не отправляются, не подтверждают запись
и не выдумывают адрес парковки или сроки оформления документов.
Это учебный пример для пяти заданных текстов: перефразировки, отрицания
и обращения с несколькими темами могут потребовать доработки правил.
